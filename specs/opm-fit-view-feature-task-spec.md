# 适应画布

Work Mode: change；Risk Level: L2；Task Type: feature。
Active Playbooks: frontend-vue (primary), testing。

## 目标与边界

提供真正的适应画布操作，让当前可见 OPD 内容进入视口；保留独立的恢复 100% 操作。
允许修改前端 OpdCanvas 及节点渲染层中的重复缩放调用、工作台视口编排、store 缩放范围、局部视口工具及对应测试、工作台设计文档和本规格。禁止修改后端、公共 API/schema、配置、依赖、其他页面、.harness 和已有案例内容；保留所有既有脏工作。
非目标：改变模型坐标、自动触发布局、最少连线交叉、持久化视口、语义缩放。
契约影响：无 API/schema/config/data 变更；原 p03-zoom-fit 从恢复 100% 改为适应，新增独立 p03-zoom-reset。

## 约定与验收

- A1：适应当前实际 SVG 内容（节点、状态、展开特征、装饰、连线及文字），保留边距，最高 100%；按外层画布实际宽高计算，包含 390px 窄屏。缩放范围 0.01%–400%，百分比保留最多两位小数。空图恢复 100% 和原点，无异常。
- A2：缩放数字与实际比例一致；选择/高亮不重置适应结果；适应模式中改变内容或画布大小重新适应；手动缩放/平移退出自动适应，缩放围绕实际可见区域中心。恢复 100% 是独立操作，只恢复比例。
- A3：自动布局初次预览不强制启动适应，已有适应模式随预览内容更新，用户可点击适应；适应模式下切换方向重新适应。取消/Escape/失败或失效恢复预览前的比例、平移和外层滚动；确认成功保留当前预览视口。不额外产生布局命令、保存、编辑序号或撤销历史。
- A4：只读版本同样可适应/缩放。原五个案例逐一核验桌面和窄屏，零 commands/save/pin；新建隔离测试模型在真实画布核验视口、预览与保存后只读，无页面异常。

## Plan

1. 复用 X6 实际 SVG 边界、scale/translate API，局部封装视口状态和异步挂载/resize 更新。

3. 定向规则/组件测试与真实画布 e2e；回归自动布局、类型检查、lint、构建和 diff。
