> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

元数据：change / L2 / feature / none (primary)。profile 与 Task Type 文件缺失，使用仓库硬规则。

## Spec
- 目标：在布局工具后、创建元素前增加调色盘，统一调整对象、过程、属性、操作、状态的边框和填充。
- 非目标：单节点配色、改变颜色作用域或保存协议、移除属性区入口。
- 允许：新增 CanvasColorPalette.vue 及其测试，WorkbenchSurface.vue、本规格；禁止 API、schema、配置、依赖及其他文件修改。
- 契约影响：无；复用 nodeColors 状态和 saveNodeColors。
- C1：点击按钮展开五行两种颜色，支持关闭、外部点击及 Escape。
- C2：每类颜色独立提交，保留另一字段，选回默认色清除覆盖；支持各类恢复默认。
- C3：只读、加载中、保存中禁止更改；错误可见；保存成功后由既有共享状态更新。
- 验证：组件交互测试、类型检查、lint、diff 检查；手工可点击调色盘逐类改色并刷新核对。
- 回滚：删除新增组件与测试，撤销工具栏接入。
