# 画布贝塞尔关系线

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode: change; Risk Level: L2; Task Type: feature.
Active Playbooks: frontend-vue (primary), testing.

## 目标与边界

在现有 X6 渲染层按矩形/椭圆边界、端点方向和距离生成平滑三次贝塞尔曲线，分散同侧连接点，避让非端点节点。灰色细线保留 OPM 箭头、空心/实心、控制标记语义。自动布局改善分支合流对齐和通道间距。

允许修改 apps/web 的关系渲染、布局、对应测试、工作台打包版本及本文；允许将新工作台包接入 opm-platform/apps/web-console 的本地依赖。保留已有配色及用户改动。禁止公共 API、持久化 schema、数据库、新依赖、部署变更及无关重构。不自动保存或重排现有用户模型。

契约影响：仅内部 RenderSpec 增加端点锚点；既有 edge_routes 手工点与显式直线/折线继续读取。调用闪电线、自调用环的 OPM 符号几何保留。

## 验收

- A1 默认曲线由边缘出入，控制柄沿边界外法线，末端箭头由 X6 沿实际曲线切线定向。
- A2 近远距离弧度有界，矩形/椭圆、多线汇入、平行反向线、跨层障碍均有针对性验证。
- A3 拖动节点后重算锚点及路径；手工路径可编辑、保存和恢复自动曲线，显式旧样式兼容。
- A4 线条/标记为灰色细线，选中仍蓝色，空心/实心区别及对象/过程/状态配色保留。
- A5 显式自动布局可预览，分支合流居中，节点不重叠；载入不擅自重排节点。
- A6 定向测试、工作台构建/类型检查和接入宿主后的浏览器验证通过。

## 实施计划

1. 独立几何函数处理端点分散、三次曲线及障碍绕行；注册内部 X6 connector。
2. 接入 RenderSpec、增量更新、候选预览及路径编辑器，统一线条绘制。
3. 改进分层布局的层居中及连接密集区域间距，沿用已有预览确认流程。
4. 定向验证，构建 platform.14 并更新宿主依赖，启动前端进行实际渲染检查。
