# 项目弹窗运行时信息与全局导航修复

Work Mode：change；Risk Level：L2；Task Type：bugfix；Active Playbooks：none (primary)。

## 目标与非目标

消除创建项目弹窗中的过期 Profile 版本和示例保存路径，以及工作台中无可见效果的全局导航按钮。本轮不重设计卡片、OPD 树、底部面板或窄屏布局，不新增工作台导航折叠能力。

## 复现与根因

当前 5177 前端的项目创建弹窗固定显示 `ISO 19450:2024 草案 0.1.0` 和 `~/OPM Studio/<项目名称>`；模型与工作台显示 0.2.0。组件没有读取启动资源的 `window.__OPM_ACTIVE_PROFILE_BINDING__`。

工作台右上角导航按钮点击前后，OPD 导航宽度均为 230px，仅按钮字符变化。按钮修改全局项目侧栏状态，而工作台没有渲染该侧栏。既有项目弹窗测试覆盖创建、焦点恢复和错误提示，没有覆盖运行时信息；缺少全局布局在工作台路由下的按钮可用性回归。

## 边界与契约

允许修改 `apps/web/src/modules/projects/ProjectLibraryView.vue`、对应组件测试、`apps/web/src/layout/AppLayout.vue`、新增对应组件测试、本规格和 `docs/checklists/` 对应记录。其他目录禁止修改。

不修改公共 API、Schema、后端、配置、依赖、用户数据或 `.harness/`。复用已经下发的启动 binding，不增加请求。已知 Profile ID 显示人可读名称和实际版本，其他 ID 如实展示；缺失信息时明确版本未提供，不猜版本。创建项目仍由运行时管理存储，仅修正文案。全局项目导航按钮仅在实际存在项目侧栏时显示。

## 验收与验证

- UI-01：已知 Profile 的版本来源于启动 binding；不同版本和未知 Profile ID 均准确展示；缺失 binding 不显示编造版本。
- UI-02：创建项目弹窗不再把示例目录当作真实存储路径展示，创建、取消与焦点恢复行为正常。
- UI-03：工作台不显示无作用的全局导航按钮；项目页导航展开、收起及从工作台返回后仍正常。
- UI-04：定向组件回归、前端类型检查和 lint、真实浏览器桌面与窄屏检查、`git diff --check` 通过。浏览器检查不提交创建、修改或保存请求。

## Plan

先补运行时 binding 与路由可用性回归并确认旧实现失败；再复用启动信息修正显示及按钮条件；执行定向组件验证、类型检查和 lint；最后使用运行中的前后端验证弹窗和路由往返并保留截图。

## 回滚

仅撤销本轮两个组件及对应测试、规格和 Checklist 的增量改动，不变更已保存的项目与模型。
