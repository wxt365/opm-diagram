## Spec
目标：减少一次撤销/重做的重复历史请求，普通节点恢复不等待辅助信息，保持既有编辑和恢复行为。
非目标：修改编辑响应、乐观编辑、后端性能改造、改变授权或持久恢复链。
允许：apps/web/src/stores/workbenchRuntime.ts、apps/web/src/modules/workbench/WorkbenchView.spec.ts、本规格；隔离测试模型的浏览器验证与回收。
禁止：公共 API、schema、配置、依赖、后端、真实用户模型及 .harness 写入；保留此前布局修复。
契约影响：无公共契约变化。同模型、编辑身份、版本和游标的并发历史读取合并，结果完成后不缓存。普通撤销辅助信息后台刷新；子图拓扑恢复、未知类型和缺失图回退仍等待导航刷新。
验收：A1 隐藏/打开历史面板时，节点恢复后同页仅请求一次历史；手动刷新、分页、失败重试和 token 隔离仍有效。A2 普通恢复不被慢 details 阻塞，旧响应不能覆盖新编辑。A3 子图恢复和 NOT_FOUND 回退保持导航刷新等待；原有保存、布局、只读和错误路径通过回归。A4 真实浏览器验证新增、删除、撤销、重做并记录请求数量和耗时。
验证：针对性测试先确认失败，修复后运行工作台、历史和布局回归、typecheck、lint、diff check；浏览器使用临时模型，不修改用户模型。
回滚：仅还原本规格及本次运行时/测试增量，保留前次未提交改动和模型数据。

## Plan
1. 在现有运行时中共享在途历史查询，显式面板刷新并发复用恢复查询。

4. 增加请求数量和慢响应回归，执行自动化及真实页面验证。
