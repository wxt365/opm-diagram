# 对话式智能建模助手第一版实现

Work Mode：change；Risk Level：L3；Task Type：feature；Active Playbooks：frontend-vue (primary)、backend-springboot、testing。

来源：用户授权按候选设计实施并使用指定 DeepSeek 服务。设计入口为 `docs/design/opm-conversational-modeling-design.md`。本规格冻结本次实现范围。

## 目标与非目标

交付工作台对话面板、DeepSeek Harness 运行、当前模型及父子图读取、多轮持久对话、语义修改提案预览及用户应用、取消/停止、冲突检查、回执恢复与画布同步。

按设计第一版仅应用安全的单命令提案。复合请求明确拆成分别确认的步骤，不称为整组事务；跨图写入、自动创建细化子图和整组语义撤销禁用。单图内允许 Runtime 能力提供的对象、过程、状态、关系、名称及布局修改。只读版本禁止提交。跨图共享语义修改展示影响并阻断，布局只作用本图。跨模型修改、通用 shell/文件操作、多用户部署和数据库迁移不在范围内。

## 修改边界

允许新增 `apps/assistant/` Node 服务、专用 Harness profile/工具、相应根 package/lock 配置、`.gitignore`、安全配置示例、`apps/web/` 的助手 API/面板/工作台接入/Vite 代理、`docs/` 与 `specs/` 中本任务文档、`tests/e2e/` 定向案例及启动脚本。必要的 Runtime 查询接口可在既有 Controller/Service/定向测试中补充，但先记录契约；默认优先复用现有草稿查询及命令。

允许必要的 Harness 依赖与服务端配置，密钥仅写入已忽略的本地环境文件。禁止修改用户模型数据、Profile/Golden、现有迁移、范围外文件、`.harness/` 和 Harness 源仓库。保留上轮四份设计文档改动。

## 执行契约

助手 HTTP API 使用项目/模型/Context/Conversation 的稳定身份；本地会话鉴权从 Runtime 验证，浏览器密钥不得流入模型。工具只开放读取、能力查询及提出单命令操作，禁止直接执行写入。提案持久绑定原始 token、目标及服务端生成的能力授权；用户应用时固定命令 ID，提交既有 EDIT 协议并记录结果。取消提案零写入，token 变化使提案失效；未知提交结果先查询回执，不自动重发新命令。不同图切换不重定向已有请求。整个模型检索同 ID 的共享影响，未知/读取不全时阻断修改。

每项目最多一个生成任务；进程停止只终止该项目生成，已有提案/提交独立存储。对话和模型真值分别持久化，重启恢复并读取最新事实。响应不包含凭据。服务绑定 loopback，使用请求来源和本地 token 校验，限制请求与工具结果尺寸。

## 验收

- IM-01：真实 DeepSeek 模型经 Harness 生成回答及提案，多轮补充读取最新画布。
- IM-02：对象、过程、状态和关系经既有能力授权提交，预览不写入；应用后 OPD/OPL/问题同步，保存重开一致。
- IM-03：父子图读取、跨图影响/共享身份判断、只读/越界拒绝、手工编辑冲突和取消零写入。
- IM-04：刷新/服务重启恢复对话；停止、重复应用、断线及未知回执不产生重复修改。
- IM-05：Node 定向测试、Vue 定向测试/类型/lint、真实浏览器桌面/窄屏和真实模型调用验证；准确记录未覆盖项。

## Plan

先核对可安装 SDK 与专用工具接入，再完成服务/持久提案及定向测试，接入工作台面板与预览，最后运行隔离模型的实际对话、画布修改及保存恢复验证。SDK 版本与可调用模型以实际握手/服务响应为准，不能静默替换用户指定模型。

回滚：撤销新增服务及入口代码；保留助手本地历史与已提交模型，避免以旧状态覆盖用户数据。无需数据库迁移。
