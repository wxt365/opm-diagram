## 目标与非目标

契约影响：允许既有客户端 Authorization 请求头通过受信来源的 CORS 预检；不改变身份认证。画布仅调整表现层计算与命中，不改变模型/命令/保存契约。

## 验收
- AC1：真实跨域客户端携带 token 可完成助手 list/watch；非法来源、未知请求头、无效会话仍拒绝。
- AC2：现有 100/500/1000/3000 节点与密集关系性能用例在本机复测完成，拖动达到现有 <3000ms 门槛，选择/布局达到既有门槛；保留未修改图形、状态跟随和手工路径语义。明确记录浏览器版本和环境限制。
- AC3：包含 State 的 Object 在未被 State 覆盖的内部区域能够普通点击/拖动；State 自身和独立 Object/Process 可正常命中，自动布局原点击阻断不再发生；不得靠 force 点击或取消状态交互达成。
- AC4：相关单元/浏览器回归、lint、类型检查通过；原有无关失败如实列出。

## 验证与回滚
先执行 HTTP/画布相关定向单元测试，再执行真实浏览器连接、命中和性能测试，最后前端全量单元/lint/构建及助手全量测试。隔离存储，仅 loopback，无真实 LLM 计费调用。回滚只撤销本任务新增/修改文件，不 repair 数据库，不修改用户数据。
