# 项目功能流程修复

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode: change; Risk Level: L2; Task Type: bugfix; Active Playbooks: none (primary).

## Spec

目标：修复上一轮审查的六项功能问题：跨项目异步回写/跳转、创建重试幂等、打开模型失败反馈、OPD 助手未发送输入与附件丢失、回收站新建混入列表、搜索文案与能力不一致。
非目标：启动入口与运行配置；图片/PDF/备份/基线等产品流程建议；公共契约和后端变更。
允许：apps/web/src/stores/projectModel.ts 及新增定向测试；apps/web/src/modules/projects/ 下三个视图/对话框及测试；apps/web/src/modules/workbench/AssistantPanel.vue 及测试；apps/web/src/shared/api/localRuntimeApi.ts 及测试；本规格及 checklist。禁止：其他实现文件、.harness、schema、公共 API、配置、依赖及后端。不覆盖工作区既有差异。repo-profile、task-types 和 playbooks 缺失，遵循 AGENTS.md。
契约影响：无；创建重试在 API 实现内部保留完整请求，方法签名和 wire 格式不变。

验收 F1：创建、打开、导入、生命周期操作的迟到结果不污染另一项目列表、计数、错误状态或触发错误跳转；同页多次打开以最新操作为准。
验收 F2：当前页面会话内，同目标同参数的失败创建重试复用完整请求（包括 request_id、command_id 和绑定）；成功后释放请求，再次主动创建分配新身份；参数或项目不同不串用。
验收 F3：模型打开失败在列表外独立显示且可重试，列表保留；创建成功但打开失败不要求重新创建。
验收 F4：同一助手组件内切换 OPD 保存各自未发送输入、已选附件及更正编辑草稿，返回恢复；不会发送到另一 OPD，迟到文件读取也不得污染另一范围。
验收 F5：回收站隐藏新建入口；创建在途切到回收站后，不将活动模型插入回收站。
验收 F6：项目搜索提示明确为搜索项目名称，既有检索行为不变。
验证：新增自动回归先复现，再验证修复；完整前端 Vitest、vue-tsc、定向 ESLint、git diff --check。使用模拟接口，不使用真实用户模型。
回滚：仅回滚本次允许文件差异，无数据迁移，保留既有工作。

## Plan

1. Store 维护活动项目身份代次，隔离异步状态；视图同时检查路由与生命周期，导入对话框检查读取/提交代次。
2. API 内部以路径与输入为键缓存创建请求原文，成功才释放，避免后端对完整请求摘要的幂等校验冲突。
3. 打开失败使用独立反馈区与原模型重试；回收站隐藏创建按钮并在 Store 保持状态过滤。
4. 助手组件按原会话范围键缓存编辑器草稿，切换时保存/恢复并隔离文件读取。
5. 搜索提示收敛到实际项目名称检索；执行定向与完整验证。
