# 工作台底部面板高度调整

Work Mode：change；Risk Level：L2；Task Type：feature；Active Playbooks：none (primary)。

## 目标与非目标

让 OPL、问题、操作历史和架构方法面板的展开高度可调整，改善关联表单和 6×1 内容的查看空间。默认保持 240px，折叠保持 38px；切换 TAB、OPD 和收起再展开保留当前工作台内的高度。

不重设计架构方法内容或移动端整体布局，不保存用户偏好到服务器或浏览器存储，不修改模型布局、OPL、校验、保存及版本逻辑。刷新工作台恢复默认高度。

## 边界与契约

允许修改 `WorkbenchView.vue`、`WorkbenchBottomPanel.vue`、新增局部分隔条组件及对应测试、工作台和窄屏样式中的底部行高、本规格与对应 Checklist。允许补充定向浏览器回归文件；禁止改动其他页面、公共 API、Schema、后端、配置、依赖、用户数据与 `.harness/`。保留上一轮未提交改动。

高度作为工作台视图局部状态，以 CSS 变量同时驱动桌面和窄屏布局。通过现有画布尺寸监听适配，不重新挂载画布。组件事件仅属前端内部交互，不改变 API。

复用既有展开/折叠及 TAB 操作。分隔条支持鼠标/触摸 Pointer Events、键盘和双击恢复。展开高度最低 210px，最高 640px，并按窗口高度、实际工作台头部高度及 240px 画布区域限制；极矮窗口上限至少为默认 240px，沿用页面原有最小高度/滚动规则。桌面布局正常高度下保留至少 240px 主区域。窄屏沿用画布最小高度与页面滚动布局。

## 验收与验证

- PANEL-01：拖动分隔条实时调整底部高度与桌面画布空间，TAB、OPD 切换、收起/展开保持已调整高度；默认与折叠高度兼容既有行为。
- PANEL-02：支持上/下方向键调整 20px、Home 最小、End 最大、双击恢复 240px；具备 separator、方向和范围等无障碍语义。
- PANEL-03：高度上下限与窗口缩小钳制正确；Pointer cancel、捕获丢失、失焦、折叠及组件卸载停止拖动，监听和 observer 清理；忽略非主指针与非左键。
- PANEL-04：真实浏览器验证桌面和窄屏、四个 TAB、画布尺寸与适应视图、只读版本；确认调整不提交模型命令。定向组件回归、类型检查、lint 和 diff 检查通过。

## Plan

封装仅负责指针、键盘和可用高度约束的分隔条组件；底部面板转发高度事件，工作台局部状态驱动 CSS 行高；补边界和集成回归；在实际 Runtime 的已有案例上验证缩放、折叠、TAB 和 OPD 往返，不编辑模型。

## 回滚

撤销本轮组件、样式和对应测试的增量改动，保留上轮修复；不涉及用户模型或持久化数据回滚。
