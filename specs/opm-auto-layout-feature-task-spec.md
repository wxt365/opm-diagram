# 自动布局预览与确认应用

Work Mode: change；Risk Level: L2；Task Type: feature。
Active Playbooks: frontend-vue (primary), testing。

## 目标与边界

为当前草稿 OPD 提供从左到右、从上到下的自动布局预览；用户确认后使用既有 UPDATE_LAYOUT_BATCH 和布局撤销/重做保存。

允许修改 apps/web/src/stores/workbench 的布局计算、workbenchRuntime.ts、工作台菜单/页面/画布的预览接入、对应测试、docs/design/opm-modeling-workbench-page-design.md 和本规格。禁止修改后端、公共 API/schema、配置、依赖、其他页面、.harness 和已有案例内容；保留此前脏工作。

非目标：跨 OPD 自动布局、手工折线顶点编辑、最优交叉数保证、拖动吸附、网格布局参数面板、自动保存既有案例布局。

契约影响：无；仅修改 owned occurrence 布局，名称、关系、语义及尺寸保持不变。

## 实现约定

- 作用于当前 OPD，忽略多选范围。reference 元素固定；它们作为避让障碍。owned 状态随所属节点平移，保留相对位置及容器尺寸；特征在所属节点右下方按稳定顺序摆放，避开主节点水平流程区域，含特征状态。无合法 owner 的 owned 状态拒绝布局。
- 基于当前关系构造分层图，状态/特征端点归入所属顶层组；循环通过强连通组折叠，孤立/无向或双向关系稳定安排。层与层间留出间距，组内元素不重叠；固定元素整块避让。方向仅影响顶层组排列。
- 预览显示实际节点和连线，明确“尚未应用”，支持切换方向、取消和 Escape。预览阶段不写服务器，不增加编辑序号/历史；画布几何编辑锁定。
- 确认复核原草稿身份与当前 OPD；源内容、布局、图或版本变化时取消旧预览；只读、提交中、加载中和关系候选期间不可开启/应用。
- 有效确认一次批量命令，一步撤销/重做；无变化零提交；失败沿既有待确认恢复逻辑，恢复原确认几何，不能显示假成功。
- 桌面及 390px 窄屏可操作预览条；取消恢复原节点和连线几何。

## 验收

- A1：两种方向的分层排列可预测、循环可终止、输入顺序不影响结果；孤立节点和不同尺寸不重叠。
- A2：状态相对位置/尺寸、特征与状态组成组、reference 固定及避让；缺少 owner 拒绝。
- A3：真实画布预览改变节点及连线，零请求，取消/Escape 还原，方向切换及窄屏可用。
- A4：确认一次请求且支持撤销/重做、保存重开；不修改语义；失败恢复；无变化零提交。
- A5：旧预览不能应用到新 token/OPD/版本；只读、关系编辑、提交中和空图禁用。
