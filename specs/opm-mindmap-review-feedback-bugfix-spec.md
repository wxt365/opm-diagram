# 脑图语义阻断的诊断与修正反馈

Work Mode：change；Risk Level：L2；Task Type：bugfix；Active Playbooks：frontend-vue (primary)、testing。

## Spec

目标：转换被阻断时直接显示具体问题，提供可编辑的修正请求入口；分析助手读取当前版本对应的失败转换报告并核对事实，不机械照搬审查意见。

非目标：自动选定咖啡豆/咖啡粉业务身份、自动提交模型、取消语义审查门槛、全自动转换修复。

允许：AssistantPanel.vue、mindmap-service.mjs、标准审查 Skill 的证据要求、相关测试、助手 README 与本规格。禁止：公共 API/schema、持久化结构、依赖、配置、用户脑图/正式模型、其他脏变更、.harness 与 Git 提交。

契约影响：无公共契约变化；read_analysis 仅增加本轮工具上下文诊断。旧版本报告保留历史，不能当作当前版本的修正依据。

事实：用户 demo 转换平台通过，报告有 5 ERROR/3 WARNING；称豆同时对同一对象使用消耗/产出/作用，研磨消耗咖啡豆同时改变其状态。报告同时误称研磨产出的是咖啡豆，实际是独立咖啡粉。原界面把具体问题折叠在笼统错误后；read_analysis 不提供失败转换报告。之前测试覆盖转换入口与截断，未覆盖失败报告回流。

验收：RF-01 最新阻断报告默认展开，优先显示具体错误与建议，历史报告保持折叠；RF-02 修正入口只填入可编辑请求，不自动发送，不覆盖未发送输入，遵守只读/运行状态；RF-03 read_analysis 返回同脑图、同 revision、同模型 token 的最新阻断报告和定版图元/步骤，过期报告不注入；RF-04 分析与审查指导要求核对实体身份、端点、状态归属，不禁止同过程对不同对象使用不同关系；RF-05 定向回归、typecheck/lint 和真实浏览器诊断/填入操作，核对用户数据零写入。

验证：先新增失败回归，后实现；使用本地 fixture 测试诊断回流和过期隔离，浏览器只展开原报告并填入请求，不发送原资料到外部模型。未完成业务选择前不改分析；供应商语义判断改进不以静态测试宣称已证明。

回滚：撤销本轮局部改动，恢复诊断折叠/无回流的旧行为，保留用户全部数据。
