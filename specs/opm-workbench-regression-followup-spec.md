> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode: change; Risk Level: L2; Task Type: bugfix; Active Playbooks: none (primary)。仓库 profile、bugfix Task Type 文件不存在。

## 目标与边界
修复检查发现的 State 未提交输入丢失及显式折叠列表在重挂载时被覆盖。允许修改工作台组件及其测试、相关使用文档和本任务 specs；禁止修改公共 API、schema、配置、依赖、后端及无关代码。保留已有未提交修改。

非目标：重新设计 State 命令、折叠持久化或扩大验收矩阵。契约影响：不增加公共契约；显式折叠列表按值恢复，默认策略由工作台提供。

## 验收
- AC1：State 名称/角色的脏输入在全局保存、选择切换、关闭前提交；提交失败、空名称或不可编辑时阻止继续，保留输入。
- AC2：显式保存和切换重叠时不重复提交；无修改时不发命令。
- AC3：画布初始及异步加载均尊重显式空/部分折叠列表；正式工作台未有选择时保持默认折叠，裸快照保持展开。
- AC4：定向组件测试、前端回归、lint、类型与构建通过。

## 验证与回滚
先定向 Vitest，再前端全量、lint、生产构建。通过组件暴露的统一 finishNameEdit 覆盖保存/选择/关闭共同入口。回滚仅撤销本任务增量，保留前轮修改。
