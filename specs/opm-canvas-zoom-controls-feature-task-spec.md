# 画布右下角缩放控制

Work Mode: change；Risk Level: L2；Task Type: feature；Active Playbooks: frontend-vue (primary), testing。

## Spec

目标：移除右下角重复版本信息，保留顶部版本标识；将缩放按钮和可输入百分比放在画布右下角，提供常用比例、适应和恢复菜单，工具栏支持真正的全屏。
非目标：视口持久化、模型/布局规则、滚轮手势改变和工具栏其他操作重构。
允许：WorkbenchView、局部视口组件及样式、相关组件和真实浏览器测试、页面设计文档、本规格。禁止：后端、store业务规则、API/schema、配置、依赖、.harness、原案例和其他无关改动。
契约影响：仅前端视口交互。原比例范围0.01%–400%、滚轮锚点和只读视口行为保持；lastAction中的连线操作提示仍在画布左下方显示，普通版本/选择状态不再在画布重复显示。

- A1：缩放控件固定在画布可见区右下角，顶部不重复；顶部保留版本标识；连线时仍有操作提示。
- A2：百分比可输入整数、小数和可选百分号，Enter/失焦应用，Esc取消；非法、非正数输入恢复当前值并提示；有效值限制到既有范围。常用比例25/50/75/100/125/150/200/300/400%，适应、恢复100%菜单支持键盘和点击外部关闭。
- A3：工具栏全屏/退出全屏及浏览器退出同步状态，全屏中菜单和视口可用，失败显示提示；只读可用。
- A4：真实画布验证输入/菜单/按钮/滚轮同步SVG比例、不产生模型写入，缩放后选择/移动有效；桌面/窄屏布局、全屏及退出验证；定向组件、typecheck/lint/diff通过。

验证：复用现有Playwright隔离模型并移入回收站，保留原案例；定向Vitest及静态检查。回滚：仅撤销本规格所列前端增量。

## Plan

1. 用局部组件管理输入、比例菜单和全屏状态，复用现有store视口入口与canvasEditor适应/恢复能力。
2. 右下角控件置于滚动框外；菜单在画布内向上展开，按可见高度限制，支持全屏。
3. 更新依赖旧控件结构的测试和设计说明，执行真实画布和定向回归。
