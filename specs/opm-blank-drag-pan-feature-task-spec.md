# 选择模式拖动空白平移

Work Mode: change；Risk Level: L2；Task Type: feature。
Active Playbooks: frontend-vue (primary), testing。

## 目标与边界

选择模式下按住鼠标左键拖动画布空白即可平移，减少选择/平移工具切换。
允许修改 OpdCanvas、WorkbenchView 的选择工具提示、局部空白拖动控制及对应组件/浏览器测试、工作台设计文档和本规格。禁止修改 API/schema、后端、依赖、配置、store 模型/选择业务规则、其他页面、.harness 和既有案例内容；保留已有脏工作。
非目标：框选、触摸手势扩展、Space 快捷平移、节点吸附或调整关系语义。契约影响：无；仅本地视口改变。

## 验收

- A1：选择模式左键拖动空白平移视口，4px 阈值内的轻微抖动不平移；拖动不清空已选元素，不产生草稿命令/编辑序号/布局历史。点击空白仍取消选择。
- A2：元素点击/多选及拖动保持原行为，关系创建及已有平移工具保持可用。只读与布局预览中也允许空白平移；右键和关系手势期间不启动新平移。
- A3：鼠标释放到画布外、pointercancel、失去捕获、窗口失焦和组件离开时结束拖动，不留下粘住状态。拖动时使用抓取光标。
- A4：真实浏览器桌面/390px 窄屏创建元素后验证平移、选择保留、空白点击、节点移动、连线、只读和释放后停止；回归多选及适应视口。

## Plan

1. 局部 Pointer Capture 处理空白左键，使用已核实的 X6 translate API；与现有平移工具独立，避免 X6 对不可移动节点/边的 unhandled 事件误平移。
2. 保留 X6 点击流程；仅拖动结束的 blank:click 阻止清空选择，下一次点击恢复。
3. 定向组件验证与真实画布测试，执行类型/lint/diff检查并同步交互文档。
