# 脑图转换阻断与助手入口修复

Work Mode：change；Risk Level：L2；Task Type：bugfix；Active Playbooks：frontend-vue (primary)、backend-springboot、testing。

## Spec

目标：准确说明属性等首版未支持项，集中展示并定位转换阻断项；左侧分析助手可直接触发既有转换入口，沿用目标与明确排除选择；模型回答不再要求新开 OPD 或新会话。

非目标：属性转换、多图转换、扩大模型工具权限、自动排除或自动提交正式模型、新依赖/API/schema、Git 提交。

允许：MindmapPanel/MindmapModel、AssistantPanel、WorkbenchView，助手分析指导/编译器及相关测试/文档、本规格。禁止：用户脑图正文/正式模型、持久化契约、密钥配置、迁移、`.harness/` 与无关文件。

事实：demo 脑图 revision 36 存在 ATTRIBUTE“目标粉量”等；编译器只接受 OBJECT/PROCESS/STATE，却统一提示“请明确类型”。分析模型工具只有 read_analysis/save_analysis，指导未说明已有转换入口，回答要求新开会话。AssistantPanel 将全部业务错误当连接错误，误显示“重新连接”。前轮有效咖啡子集转换验证未覆盖属性诊断/会话指引，安全的权限限制保留。

契约影响：不变；前端预检辅助用户处理，服务端编译守卫仍最终拒绝未排除内容。显式排除保留分析原文且不默默跳过。聊天入口复用当前脑图目标/选择/保存及现有 convert API，不让模型直接写正式图。

浏览器验证补充：明确排除项此前未进入语义审查需求，导致审查将保留在脑图的属性误判为漏建。本轮在既有分析转换需求中写入明确排除的 ID/标签与目标，仍不改变模型、审查规则或工具权限。完整咖啡脑图审查达到输出上限，保留不完整报告的阻断守卫；不以小模型成功替代该完整模型的语义结论。

验收：MG-01 全部首版不支持项显示准确原因，可定位、勾选排除，未处理不能发转换；MG-02 左侧按钮沿用脑图已选目标/排除与保存流程，历史只读/生成禁用；MG-03 分析指导明确可以在当前视图生成预览，无须新建会话；业务错误不显示重连；MG-04 定向组件/服务测试、静态检查及真实浏览器定位/排除/预览验证，不自动确认用户模型。

验证：先失败回归，再组件/助手、typecheck/lint；真实本机浏览器操作、独立模型生成预览、校验就绪或准确报告语义阻断，正式 token 保持。回滚：撤销本轮局部改动，保留全部原分析资料/映射。
