# OPM 画布节点拖动性能修复

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode: change · Risk Level: L2 · Task Type: bugfix

Active Playbooks: frontend-vue (primary)、testing（沿用 opm-platform/.harness）。

## 目标、边界与契约

减少拖动单节点时无关关系和属性组的正交寻路、SVG 更新，保留边界端口、主干支线、箭头、手动路径、状态跟随和保存恢复。

允许修改 apps/web/src/modules/workbench/OpdCanvas.vue、opd/core 下的拖动/渲染/路由及定向回归测试、工作台打包版本、本规格，及 opm-platform/apps/web-console 的工作台依赖和 vendor 包。

禁止修改数据库、后端、公共 API/schema、新增依赖、无关重构或业务模型数据。原有未提交修改全部保留；浏览器写操作仅使用已有隔离测试模型。

复用 X6 Manhattan 及 layout.edge_routes；仅调整前端计算/失效策略。无需迁移或新增配置。大型图的绝对帧率受密度、连线长度和硬件影响，不把样例耗时作为所有图的承诺。

## 验收与验证

- A1：拖动无关节点不强制刷新全图连线；移动障碍覆盖一条路径时，该路径能重算避障，忽略所属外框等允许穿越的节点。
- A2：属性组仅在本组内容/几何变化或其路径受障碍影响时重算；展开、折叠及手动路径继续正常。
- A3：路径配置按变化字段更新；拖动中不反复重排全图标签，松手后校正。
- A4：定向与前端回归、类型检查和工作台构建通过；隔离浏览器验证正交、避障、节点/状态移动及路径保存恢复。
- A5：用与修复前一致的浏览器隔离样例（200/60、400/120、属性展开、跨图长线）对比耗时；宿主实际加载新包。

## 验证结果（2026-10-21）

- Vitest 67 个文件、571 项测试全部通过；新增无关属性组/路径不刷新、端口变化不重设整条路径、障碍进入/离开/扩容及不可达端点停止搜索回归。vue-tsc 应用和工作台声明检查通过，Vite 工作台构建通过。
- 真实 Chrome / X6：移动无关障碍，普通线及展开属性线避开正文；远处连线更新次数为 0；结构分支、空心三角、标签、移动/扩容保持正交。
- 隔离 PG 模型的真实页面：节点及中间线段鼠标拖动、保存、重开通过；手动路径与实际路径恢复一致，无页面异常。业务模型未修改。
- 工作台包 0.2.2-platform.22 已安装至宿主，package、lock、tgz SHA512 一致；3000 Vite 使用 --force 重启。宿主页面 details 200、10 条路径保持正交、无页面异常。

相同本机隔离样例的单次更新耗时（每组 5 次，统计后 4 次均值，非端到端帧率）：

| 样例 | 修复前 | 修复后 |
| --- | --- | --- |
| 200 节点 / 60 关系 | 35.4ms | 3.9ms |
| 400 节点 / 120 关系 | 105.6ms | 5.3ms |
| 236 节点，12 组展开属性，108 条显示线 | 162.6ms | 15.1ms |

另测所有者及其属性共同移动，236 节点样例约 12.3ms（此组无修复前对照）。初次加载仍需绘制全图，当前优化针对拖动。密集/重叠图形仍可能较慢；节点相互覆盖、无可通行空间时保留原有正交兜底，不承诺完全避障。

实现按路径与变更节点的旧/新边界做局部失效；共享路由准备，属性组按组签名缓存。相邻边由 X6 自行跟随；属性装饰/边仅更新变化字段。拖动中延后全图标签避让，释放指针后恢复。细网格寻路上限 512，超过后使用原有正文边界避障回退；不可达起终点直接结束无效搜索。
