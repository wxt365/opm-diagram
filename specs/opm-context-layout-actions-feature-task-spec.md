# 右键菜单布局操作

Work Mode: change；Risk Level: L2；Task Type: feature。
Active Playbooks: frontend-vue (primary), testing。

## 目标与边界

在现有画布空白右键菜单加入撤销布局、重做布局及对齐/分布入口，复用原历史和排列命令。
允许：CanvasContextMenu、WorkbenchView、LayoutToolMenu 及共用排列菜单组件、对应测试、本规格及工作台设计文档。
禁止：布局算法/store业务、API/schema、后端、依赖/配置、.harness、其他页面与原案例内容。保留既有脏改动。
非目标：语义编辑撤销、节点/关系右键菜单重做、新布局能力。契约影响：无。

## 验收

- A1：空白菜单有撤销/重做；历史可用状态与工具栏一致。预览、只读、忙碌及关系候选期间不可变更布局。
- A2：对齐与分布子菜单提供现有六种对齐及两种分布；选中不足/不合法时禁用，展示现有原因。右键不丢失多选；与工具栏使用同一基准与命令。
- A3：菜单与子菜单不挤动工具栏，桌面及390px窄屏均不越界；键盘导航跳过禁用项，Escape先关闭子菜单再关闭主菜单。外部点击/滚动/切图清理沿用原行为。
- A4：真实画布创建隔离模型，实际执行对齐/分布、撤销/重做，检查几何和批量命令；回归自动布局/删除/空白平移；单测及typecheck/lint/diff检查通过，隔离模型移入回收站。

## Plan

1. 共用排列菜单条目与图标，保留工具栏测试标识；右键使用独立标识。

3. 页面传递原能力状态并调用原 requestLayoutHistory/requestLayoutArrangement；预览期间额外禁用。
4. 定向单测及真实画布验证后同步文档。
