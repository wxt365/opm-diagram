# OPD 导航宽度调整

Work Mode：change；Risk Level：L2；Task Type：feature；Active Playbooks：none (primary)。

## 目标与非目标

允许拖动 OPD 导航右侧分隔条调整宽度，改善长名称和多层树的查看；支持键盘及双击恢复。未调整时沿用桌面 230px、中等屏幕 210px 默认宽度。切换 OPD、TAB、只读版本保持当前工作台宽度，刷新恢复默认值。

本轮不调整全局项目侧栏、OPD 内容及命名、不持久化偏好、不重做移动端布局；不改底部面板高度功能。

## 边界与契约

允许新增导航分隔条组件及其定向测试，修改 `WorkbenchView.vue` 与对应集成测试、`workbench-layout.css`/`responsive.css` 的导航列尺寸及边界、本规格和对应 Checklist。保留此前未提交改动。禁止修改 API、Schema、后端、配置、依赖、模型数据、其他页面及 `.harness/`。

导航宽度为视图局部状态，通过 CSS 变量驱动 Grid。复用现有画布尺寸监听以及上轮分隔条交互方式，不重新挂载画布，不扩大为通用重构。

宽度最低 180px、最高 420px。大于 980px 时为画布保留至少 400px，并扣除打开的 320px 属性区；681–980px 时属性区在下方，为画布保留至少 320px。680px 及以下沿用上下布局，隐藏分隔条并保留已选宽度，恢复较宽窗口后按当前范围限制。

## 验收与验证

- NAV-01：拖动右侧边界实时改变导航和画布宽度，切图/TAB/版本保持宽度；默认宽度、加号和返回父图位置稳定。
- NAV-02：左右键每次 20px、Home 最小、End 最大、双击恢复屏幕对应默认值；提供 separator 方向、当前宽度及范围语义。
- NAV-03：正确处理宽度上下限、窗口缩小和属性面板开关；窄屏隐藏分隔条、无新增横向溢出；非主指针、取消、失焦、捕获丢失和卸载生命周期正确清理。
- NAV-04：定向组件回归、类型检查、lint 和 diff 检查通过；实际浏览器验证桌面、中等屏幕、窄屏、只读、触摸以及画布缩放/适应行为，无模型编辑和保存请求。

## Plan

使用导航独立容器承载滚动树和分隔条，避免树滚动影响拖动边界；分隔条封装宽度约束和指针/键盘事件，工作台以局部变量接收宽度；适配 Grid 列与响应式默认值；完成回归和实际画布验证。

## 回滚

仅撤销本轮导航分隔条、集成和列尺寸增量，保留上轮底部调整、项目弹窗和全局导航修复，不涉及用户数据。
