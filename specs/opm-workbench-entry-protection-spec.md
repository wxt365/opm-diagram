# 工作台剩余入口保护

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode: change；Risk Level: L2；Task Type: bugfix；Active Playbooks: none (primary)。repo-profile、bugfix task-type 文件不存在。

## 目标、非目标和边界
修复 OPL 定位、工具栏关闭绕过输入提交，刷新未保护 State 输入，以及记忆折叠后新 owner 首次新增特征未默认收起。
允许：apps/web 中相关工作台组件、导航 helper 及测试，使用文档、本任务 specs；按 AGENTS Failure 规则更新既有失败记录。禁止：公共 API、schema、配置、依赖、后端、无关重构。保留此前所有修改。
非目标：重设计 State 命令或在 beforeunload 执行异步保存。契约：仅内部组件事件/暴露的脏状态，公共嵌入接口不变。

## 验收
- AC1：OPL 定位与工具栏关闭等待统一提交；失败保留输入/选择/面板；成功继续。
- AC2：State 脏输入、提交中、提交失败触发浏览器离开提示；确认成功解除，不影响现有布局/分析保护。
- AC3：工作台记忆折叠后，为新 owner 首次新增特征仍默认折叠；初次/异步装载和上下文恢复不覆盖显式选择；快照不强制折叠。
- AC4：定向后前端全量测试、lint、类型/构建实际通过。

## 验证、回滚
组件集成验证实际工具栏/OPL 点击，beforeunload 可取消事件验证保护请求（不声称验证浏览器提示框），用节点更新模拟已装载图新增特征并对照重读/恢复；然后全量前端回归。回滚仅撤销本任务增量。
