# 画布空白右键自动布局入口

Work Mode: change；Risk Level: L2；Task Type: feature。
Active Playbooks: frontend-vue (primary), testing。

## 目标、范围与契约

在当前 OPD 空白区域右键显示菜单，提供「自动布局…」，复用现有预览、应用及撤销流程。
允许：工作台画布/页面/局部菜单组件、相关测试、本规格及工作台设计文档。
禁止：API/schema、后端、依赖、配置、布局算法、既有案例内容、.harness、无关重构。保留全部既有脏改动。
非目标：增加其他菜单命令、跨 OPD 布局、重做元素和关系菜单。公共契约与存储无变化。

## 验收

- A1：空白右键显示自动布局项，保留当前选择；元素/关系右键保持原菜单。选择/平移模式均可使用。
- A2：菜单沿用 canAutoLayout 并禁止预览期间重复启动；只读、空图、忙碌或关系手势期间不可应用。调用既有 requestAutoLayout，先完成编辑再预览；取消零布局写入，应用一次批量布局，可撤销。
- A3：菜单在桌面和窄屏可视范围内；外部点击、Escape、滚动/窗口变化、图切换关闭，组件销毁清理监听。
- A4：真实浏览器创建隔离模型测试右键入口、预览/取消/应用/撤销、元素及关系菜单、禁用和窄屏；结束移入回收站。定向组件回归、类型/lint/diff 检查。
