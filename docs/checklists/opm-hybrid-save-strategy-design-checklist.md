## 设计场景演算（非运行测试）

| 场景 | 文档约束核对结果 |
| --- | --- |
| t=0 首次修改，t=1~9 持续修改 | 截止仍为 t=10，不滑动到最后一次输入后 10 秒 |
| t=8 手动保存覆盖全部已接收编辑 | 取消已覆盖 AUTO；t=9 的新编辑重新建立未覆盖期限 |
| AUTO 在途，随后点击 MANUAL | 不抢占事务，同内容复用；新内容排下一次手动任务 |
| AUTO 已保存 B，最近手动为 A | 手动保存 B 建立历史事件，复用 B 内容；再次点击不重复 |
| 保存 seq=8 时又完成 seq=9 编辑 | 成功仅覆盖 seq=8，seq=9 继续 dirty，不覆盖其投影 |
| SQLite commit 成功但 HTTP 响应丢失 | 原 command_id 查询/重放收据，不能换 ID 重复编辑 |
| 压缩时 Pin 正在固定旧 token | 读保留引用保护其检查点/增量；不改为 Pin 当前 HEAD |
| 浏览器退出且最后编辑未形成检查点 | 使用已确认的 Journal 恢复，不依赖退出回调 |

未执行应用单测、浏览器测试、DDL 迁移、故障注入或容量测量；本轮只修改设计。运行功能、数据库与旧历史保持原状态。
