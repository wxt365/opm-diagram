## 主要发现

1. 助手跨域：带 token 连接，切换智能助手后 Failed to fetch，list 的 OPTIONS 被 CORS 拒绝。助手请求头白名单缺少 Authorization。原创建、保存和校验步骤通过，但 list/watch 失败使再次绑定等后续步骤未验完。
2. 性能：100 节点加载 298ms、选择 15.4ms、拖动 465ms、缩放 7.4ms、布局 4.9ms；500 节点拖动 3832ms，单项复测 3780ms；1000 节点拖动 15202ms；3000 节点拖动记录 145889ms，整体 180 秒超时；密集关系增量操作也超时。与其他回归并行运行，未排除资源竞争。
3. 节点点击：自动布局/排列用例存在 graph SVG 拦截节点点击；独立复核对象内部 (20,20) 点击成功。不得仅依据 finally 清理后的项目详情截图判断首次失败。
4. 属性折叠后仍出现一个属性节点，需对照当前规格进一步定位。
5. 重复缩放 test id 对应一个可见和一个隐藏实例，旧用例严格定位失败；检查器期待的旧分组与当前界面不同。未验证完的后续步骤不计通过。
6. 长状态名称 tspan 期望 2、实际 3，但截图视觉两行且内容完整，未确认文字截断；后续重复增长断言未执行完。
7. 冻结夹具：SaveContentDigest 的 8 个失败在 raw SHA 预检处终止；工作区 CRLF、索引 LF，与固定摘要冲突。RFC8785 同样在禁止 CR 的断言失败，不等于模型保存业务失效。
8. 后端旧 context 测试库迁移 checksum 失败，新隔离目录启动通过；故障计划校验另有 schema resource differs 与错误码前置不一致，需核对资源字节。

主回归通过的范围包括：IndexedDB 投递恢复与异常零发送 7 项、模型回收站生命周期、bootstrap 顺序、右键/Backspace 删除和固定版本重开、底部面板折叠、关系分轨、必填标签内联及取消、非法端点反馈。嵌入组件通过 owner 内状态坐标、连续空白拖动、X6 双实例隔离。
