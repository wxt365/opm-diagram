# 脑图助手的分支编辑与回复流

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode `change`。Risk Level `L3`。Task Type `feature`。Active Playbooks `frontend-vue（primary）`、`testing`。

- A1 业务与 OPM 脑图在发送时传递当前节点和聚焦分支。服务基于该脑图修订核对节点，并将上下文提供给助手。旧客户端可以省略新增请求字段。
- A2 聚焦时允许修改分支内的节点、顺序和涉及该分支的关联。保护分支根的位置及其他分支的数据。每轮局部编辑成功保存一次，重载后可按一次撤销恢复。编辑使用现有分析保存及引用校验。
- A3 业务脑图和业务建模的助手文本在回复完成前分段显示，并更新同一消息。断开事件订阅可继续读取保存的会话。OPM 共用既有事件传输。验证会话范围、生成停止和最终消息。

变更限于 Web 助手和脑图适配器、助手服务与现有事件端点、定向测试及本规格。新增字段为可选的请求上下文，数据库、分析文档、正式模型定义、依赖及正式确认契约沿用原定义。脑图逐批暂存预览属于后续阶段。回滚使用本轮对应的前后端代码回退。

核对 A1–A3 后实施。依次接入视图范围、保护分支写入、复用模型增量与事件传输。使用助手服务测试及两种隔离工作台验证。
