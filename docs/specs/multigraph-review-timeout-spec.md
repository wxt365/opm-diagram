Work Mode: change; Risk Level: L2; Task Type: bugfix; Active Playbooks: none (primary).

目标：以冻结审查快照的受审图数量及可见图元规模计算时限，不因拆图仅3个步骤而误用120秒；记录计时依据。允许修改 stage-runner.mjs、plan-finalizer.mjs 及相关助手测试、本规格/清单。禁止接口/schema/依赖/审查规则/权限/模型数据/.harness 改动。非目标：跳过审查、逐图拆分审查、自动重放模型请求。

验收：TIME-01 快照中每张受审图的节点和关系计入工作量；多图每增加一图增加60秒，每超出30个图元增加1.5秒，总默认上限600秒，基础120秒；TIME-02 无快照沿用原步骤计时与300秒上限，显式配置优先；TIME-03 诊断记录图数/图元数/计时来源，实际阶段与记录使用同一函数；TIME-04 超时保留方案，审查不通过仍不能确认，重新审查不重生成。

计划：抽出工作量函数供时限及诊断复用，基于已经冻结的review.snapshot；定向边界和真实恢复流程测试，然后重启。回滚：恢复本次代码重启，无数据迁移。
