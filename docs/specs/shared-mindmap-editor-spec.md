# 共享脑图编辑器

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode：change；Risk Level：L2；Task Type：refactor；Active Playbooks：frontend-vue（primary）、testing。

## 目标与验收

R1：OPM 与业务脑图使用同一个基础编辑器，包括工具栏、节点渲染／布局、选中、折叠、搜索、拖动改父节点、平移、滚轮／百分比缩放、全屏和侧栏开关。
R2：统一 Tab 子节点、Enter 同级、F2 改名、Delete 确认删除、Ctrl/Cmd+S 保存、Ctrl/Cmd+Z/Shift+Z 历史操作；输入法和表单输入不得误触节点操作，键盘事件不串到正式画布。
R3：侧栏统一节点详情／模型生成分区；基础文字和说明共用，OPM 语义分类／归属／引用／关系及转换检查通过插槽扩展；业务自由脑图不增加语义字段要求。
R4：原保存和转换适配器、props/emits/expose、幂等／冲突保护、已存内容、节点身份、模型来源及各自 JSON 格式不变，不迁移数据；只读／生成时禁止写入，搜索缩放仍可读。
R5：共享交互及两适配器回归、类型检查、lint／构建、真实浏览器分别编辑／保存／刷新及只读范围验证；不使用外部模型。

## 边界

允许：apps/web/src/shared/mindmap 新共享组件／树布局工具及测试；两个脑图面板、布局包装函数及对应测试；WorkbenchSurface 切换脑图时移除独有的自动 fit 调用，使两端都以100%起始、由用户主动查看全图；必要独立工作台打包入口、相关设计／规格／验证报告。禁止：后端、数据库、API/schema、依赖、助手语义和生成流程、用户模型及会话数据、大范围格式化、前序改动、提交／打包发布。

保持不变：OPM 的语义类型、状态归属、实体复用、关系和转换排除；业务的自由文本树、选中分支或整图转换与来源；各自撤销／重做、自动保存／未知回执保护、导入身份重建与正式模型确认。

不合并两种分析文档或 JSON 格式，不把树结构当成正式流程，不为统一外观改变转换范围。公用组件只能依赖公共类型／控件，不能导入业务模块。
