# OPD 助手自动应用

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode `change`。Risk Level `L3`。Task Type `feature`。Active Playbooks `frontend-vue (primary)`、`testing`。

## 验收

- A1 OPD 对话和脑图转 OPD 逐步更新画布。平台校验、独立审查通过后，以一个现有草稿命令自动应用，无需二次确认。重新审查通过后继续该流程。
- A2 停止、生成失败、校验阻断及版本冲突不写入。进入提交阶段后由命令回执确定状态，未知结果沿用原命令重试。可见预览保留到正式画布读回。
- A3 正式图允许整轮撤销、重做。来源转换历史与模型撤销状态一致，重做后重新生效。
- A4 可选的 `autoApply` 仅由新版工作台发起，不带参数的调用和原历史方案继续兼容。脑图分析对话仍通过其专用工具读写。

## 边界

允许更改 OPD 助手编排、提示与 Skill、工作台交互、现有草稿恢复与转换历史读取和相关测试。沿用 Runtime 命令、鉴权、版本与数据库结构。独立修改工具的旧契约保留，新自动应用流程统一使用整图方案。

## 实施与回滚

先复用提交队列及回执，再接入工作台回读和撤销，最后执行助手、前端、Runtime 定向验证及隔离浏览器复测。核对 A1–A4 的版本、来源及审查限制。回滚工作台的自动应用参数可恢复手动流程，已提交的草稿可用正常历史功能处理。
