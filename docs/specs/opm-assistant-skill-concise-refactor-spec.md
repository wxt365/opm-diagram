## 目标与边界

Work Mode：change；Risk Level：L2；Task Type：refactor；Active Playbooks：none (primary)、testing。

目标：压缩生成、审查 Skill 及重复提示，保持既有建模、校验、确认和权限行为。
允许：两份 Skill、现有规则/策略版本、`quality.mjs`、`harness.mjs`、`service.mjs`、`tools.mjs`、`plan-finalizer.mjs` 的提示文本，以及相关测试、助手 README、本设计文档、此规格及清单。
禁止：修改 API/schema、质量阈值、15 项审查规则语义、工具权限、依赖、持久化/前后端逻辑、真实模型、`.harness`；不提交或重启服务。
非目标：新增规则、扩大标准覆盖、新增 references 读取工具、追求字数而牺牲约束。

## 不变量与验收

- A1：生成与审查正文减少重复；生成完整预览后一次确认，本图写入、身份复用、状态/关系语义、语义布局及合理拆图建议保留。
- A2：15 项规则及条款内容不变，审查范围与历史问题区分、缺证据不判错、同版本 OPL、结构化报告及精确引用保留。
- A3：正文直接注入；规则由 `read_review_model.rules` 提供，数值由 `read_model.quality_policy` 提供；不依赖被禁用的文件/Skill 工具。工具返回字段和 schema 不变。
- A4：既有加载、质量、审查和生成回归无新增失败；用虚构案例对比精简前后模型的状态关系、密集图建议、局部审查、OPL 证据决策，明确单次样本与完整运行链路的差别。
