## 目标与非目标

按用户请求构建本机 macOS arm64 可安装测试包，交付 DMG 及实际验证记录。复用现有 Electron/Forge 工程、Web 和 Java 构建产物，随包装配可分发的 Java 17 与 Node 22，不携带开发环境或用户数据。

不发布到外部，不签名/公证，不构建 Intel Mac 或 Windows 包，不修改建模 API/schema，不提交 Git，不覆盖用户数据库与已有产物。

## 边界与契约

允许新增本规格与对应检查清单、更新桌面说明；允许在 `apps/desktop/.runtime`、`apps/desktop/out` 和系统临时目录下载、装配、构建、保存测试证据。出现可复现打包错误时只修正 `apps/desktop` 的必要打包/验证适配并记录。

最终应用沿用正式数据路径且不支持开发态目录覆盖。已核实本机 `~/Library/Application Support/OPM Studio` 不存在；运行测试前再次核实并排他创建带本轮身份标记的空目录，测试后正常退出并将该新建目录完整移入临时证据目录。若测试前已有目录则拒绝编辑；不挪动任何既有桌面数据。

禁止修改 `.harness`、业务模块、凭证、开发数据及既有服务。运行时从官方来源下载并核对公布摘要，保留许可证/来源。不移除 developmentRuntime 保护绕过分发限制。用户已明确授权生成本机测试包；无证书时标为未签名测试包，不称为正式发行版。

## 验收

- M1：Java/Node 来源、版本、架构及下载摘要可追溯，资源不含 `.env*`、凭证、用户库与测试恢复资产。
- M2：Forge 生成 macOS arm64 `.app` 和 `.dmg`，执行资源清单校验，保留原产物。
- M3：实际启动构建后的应用，确认项目库/SQLite 工作台就绪并正常退出；涉及业务编辑时使用隔离数据。
- M4：检查磁盘映像可挂载、包含应用，并提供路径、大小、摘要、安装方式和未签名说明。
