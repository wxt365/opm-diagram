# 共用脑图左右展开

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode `change`。Risk Level `L2`。Task Type `feature`。Active Playbooks `frontend-vue（primary）`、`testing`。

- B1 业务建模和 OPM 的脑图工具栏都可切换「从左到右」「左右展开」。左右展开以根节点为中心分配一级分支，子树沿所在侧展开。切换时适应全图，保留选择、树结构和同级顺序。
- B2 小地图、关系线、折叠、分支聚焦和 PNG／SVG 导出均按当前布局显示。XMind 采用与布局匹配的原生结构，导出完整主题树。
- B3 布局作为打开页面期间的视图设置使用。默认从左到右，切换布局无需保存分析。

变更范围为共享脑图组件、布局算法、XMind 结构映射与定向测试。自上而下布局另行实现。先确认布局几何与连线，再验证两种工作台的切换和文件导出。撤回本规格关联的前端改动即可恢复原布局。

## 从上到下与节点层级

Work Mode `change`，Risk Level `L2`，Task Type `feature`。使用 `frontend-vue` 主规则和 `testing` 辅助规则。

- V1 业务建模和 OPM 的脑图可切换「从上到下」。同级按从左到右的顺序排列，拖拽提示与折叠控件适应该方向。
- V2 根主题、一级主题及后续主题以不同字号、字重、底色呈现。分支聚焦时沿用主题原有层级。
- V3 适应全图、小地图和 PNG／SVG 使用同一组布局坐标。XMind 导出使用其原生向下组织结构。

修改限于共享脑图前端、导出、测试及此规格，沿用现有数据契约和布局默认值。核对项为 V1–V3。验收包括布局与拖拽回归、两种入口的浏览器验证和导出文件检查。回滚时撤回本节对应的前端改动。

## 按层级调整节点尺寸

Work Mode `change`。Risk Level `L2`。Task Type `feature`。使用 `frontend-vue` 主规则和 `testing` 辅助规则。

- S1 两种脑图通过「节点尺寸」分别设置根主题、一级分支和后续节点的宽高。打开时采用已有的 202 × 64 像素，页面内可恢复默认。设置按原树层级应用，聚焦分支时继续使用。
- S2 三种布局按实际框大小排布，连线接到边缘，小地图和 PNG／SVG 使用同一节点几何。
- S3 调整保持缩放比例和选中项，属于当前页面的视图设置。

范围为共享脑图前端、规格和定向回归。沿用现有数据契约及 XMind 格式。先统一布局与渲染所用的尺寸，再接入控件。验收覆盖异尺寸的三种布局、端点投影、恢复默认和两种建模入口。回滚时撤回本节对应的前端改动。

## 单节点拖拽尺寸

Work Mode `change`。Risk Level `L2`。Task Type `feature`。使用 `frontend-vue` 主规则和 `testing` 辅助规则。

- D1 选中节点后，可拖动左右边缘调宽、底边调高、右下角同时调宽高。缩放后按画布坐标计算变化，拖动时保持对侧边缘位置并同步更新布局。
- D2 单节点尺寸覆盖所在层级的宽高设置。可恢复选中节点的层级尺寸，属于当前页面的视图设置。
- D3 两种脑图复用交互，连线、小地图和图片导出使用调整后的几何。拖拽排序、平移、折叠和锁定沿用原入口。

范围为共享脑图前端、定向测试及本节。核对项为 D1–D3，使用组件测试及两种工作台的浏览器拖拽验收。回滚时撤回本节对应的前端改动。

## 脑图工具栏

Work Mode `change`。Risk Level `L2`。Task Type `feature`。Active Playbooks `frontend-vue（primary）`、`testing`。

- T1 编辑、文件、视图按组排列，全屏和属性在右侧。工具使用图标及悬停提示，按钮高度与业务建模及 OPD 工具一致，保留可访问名称、禁用状态和原命令。
- T2 OPM 和业务建模共用工具栏。空间不足时按组换行，布局选项、文件菜单及节点尺寸仍可操作。

目标是提高现有命令的辨识度。范围包括共享脑图、全屏按钮、规格及定向测试。新增文件格式、命令、依赖及持久化尺寸均在范围之外。API、schema、运行配置和数据契约沿用原定义。D1–D3 与 T1–T2 边界已核对。先应用单节点几何，再统一工具栏入口，最后运行组件回归和两个工作台的浏览器验收。回滚时撤回本轮关联的前端改动。
