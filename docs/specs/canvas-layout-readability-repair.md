# 画布布局与正交连线可读性修复

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode: change；Risk Level: L2；Task Type: bugfix。
Active Playbooks: frontend-vue (primary)、testing（沿用相邻 opm-platform 规则）。

## 目标和边界

对象及所属属性成组排布，减少中心拥挤、长距离折返、平行关系重叠和文字压线。保留 OPM 实心、空心、嵌套三角及原关系方向和语义，继续支持正交拖线、保存与重开。

允许修改画布自动布局、路由、标签、结构符号几何及相关回归、内置工作台包和平台包引用。允许通过已有布局入口整理并保存已识别的截图对应子图的几何，以展示修复效果；不修改模型语义、业务数据库、导入 JSON、公共 API、后端或其他主题，不引入依赖。已有未提交修改全部保留。

## 实施决策与验收

- GROUP-01：复用现有布局预览/应用/撤销/保存流程；属性子树保留所属分组，平衡整体长宽，为高连接度节点预留间距；只读节点不移动。
- ROUTE-01：自动二元关系按端点和连接方向分道，优先短且清晰的正交通道，避开节点；手动路径和结构扇出主干保持原有语义，采用有限候选并沿用现有动画帧调度，标签在拖动结束后排布。
- LABEL-01：关系标签同时避开节点、其他标签和其他连线，优先长水平段，位置稳定。
- SYMBOL-01：缩小结构关系三角的视觉占比，保持实心/空心/嵌套符号的区别、连接点和拖动操作。
- SAVE-01：预览不写入；应用只标记真实布局改动，保存后重开保持节点及手动路由；浏览不触发未保存误报。

边界已确认。先增加定向失败回归，再实施布局、路由和标签修复；执行相关测试、类型检查、代码检查及平台打包，最后用真实浏览器检查当前主题。

## 验证和回滚

覆盖多属性、嵌套属性、双向/重复二元关系、节点障碍、已有手动路径、文字压线、历史只读与保存重开。复用现有 Vitest 与 Chrome/Playwright。真实页面保存仅限核对过的目标图布局，不创建语义元素，不发起评审或发布。

回滚本轮布局/路由/标签/符号实现和工作台包引用；需要恢复现有图几何时从已有历史版本取回原几何，不撤销之前的属性标签与未保存提示修复。
