# 子图重组

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode: change; Risk Level: L3; Task Type: feature; Active Playbooks: none (primary).

目标：受限助手将当前 OPD 中已有内部元素下沉到新细化 OPD，预览父子图、统一诊断和标准审查、用户一次确认后原子保存。保留所有元素/状态/关系语义身份，不授予代码编辑权限。

允许：草稿方案契约生成器及生成产物、运行时方案执行与预览、助手工具/审查/Skill/测试、前端预览与契约类型、任务文档。允许新增 ModelPlanStep 类型和可选多图预览字段；不改数据库 schema、不增依赖、不删除语义实体、不直接修改用户数据、不改 .harness 或其他模块。

范围：当前父图已有 OWNED Object/Process 为细化父元素；显式选定当前图内部 ELEMENT occurrence。自动包含所选元素的属性/状态和内部关系；跨边界关系仍留父图，相关共享端点同时保留父图与子图出现。仅创建直接新子图，不重组其他已存在图、不迁移已有细化父元素、不自动抽象/编造边界关系。严格内缩放次序不由布局推断。

验收：SUB-01 候选正文复制预览不写库，稳定子图与图元出现身份；SUB-02 共享原 target_id、内部关系下沉、跨边界关系不丢失，状态/端点闭包校验；SUB-03 整组通过 draft journal 一次事务提交，失败不部分写入，重试幂等/版本冲突；SUB-04 仅建模工具可提出重组、审查只读，所有受影响父子图完整审查和同版本 OPL；SUB-05 前端可切换父子预览并一次确认；SUB-06 Skill 按运行时能力执行，不可用只建议。

计划：扩展既有 APPLY_MODEL_PLAN，新增受限 REORGANIZE_SUBGRAPH 步骤，稳定身份和边界规则集中后端；预览返回受影响图及各图 OPL；复用独立报告与原子确认，增多图审查范围；前端选择预览图。验证真实 MVC/存储失败与重试、助手工具/审查权限、前端切换和生成契约/typecheck。

回滚：恢复实现及生成契约并重启；未提交方案不应用，已提交重组保留正文与历史检查点，不删除数据库。旧客户端不能提交新步骤，应同步部署前后端。

发布：指导和审查 Skill 版本更新为1.4.0（允许修改助手两份版本参考文件，规则条款和质量阈值不变）；旧未提交报告需重新审查。前端重组预览条可选主图/子图，确认按钮为“确认父子图重组”。运行时不返回 affected_views 时助手仅建议。SDK按实际生成延迟加载，未安装SDK时生成不可用，不以健康接口替代模型可用性验证。
