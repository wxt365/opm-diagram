Work Mode: change；Risk Level: L2；Task Type: bugfix。
Active Playbooks: backend-springboot (primary)、frontend-vue、testing（采用相邻 opm-platform 的规则）。

## 范围

根据 characterization 关系恢复属性及所属对象，不按名称、中文分类或案例编码判断。画布保留并显示导入分类标签。允许修改平台转换器、工作台服务、共享运行时包解析器、画布投影与节点展示及对应回归；允许更新平台内置工作台包。端到端复现发现普通结构关系的 OPL 类型校验拒绝 Feature 端点，允许修复运行时此处校验并更新运行时构建，以保留属性参与的其他关联。禁止清空数据、修改源 JSON、数据库 schema、运行时公共 schema、权限及无关模块，不引入依赖。

## 验收

- ATTR-01：属性线的属性端转换为 ATTRIBUTE Feature，所属对象、跨图身份、其他关系、状态和布局保留；属性标签本身不决定节点类型。
- ATTR-02：保存、同步、重开及进入02时仍保留属性归属；不产生两条重复属性线。多归属、循环等不能无损转换的情况保留原模型并提示，不静默丢失。
- LABEL-01：节点显示原始分类的单行中文摘要，保留完整标签供查看；选中、改名、缩放及状态节点不遮挡标签或名称。
- COMPAT-01：已有旧转换结果从当前已保存模型升级，未保存/未同步内容受保护，旧运行时模型可恢复；处理幂等，不因每次打开重复迁移。

## 实施及验证

1. 用通用小模型补转换、往返及兼容回归，再验证 V3 的32个属性。

3. 宿主代理合并分类标签，前端投影保留标签并独立渲染，不拼接名称。
4. 定向 Java/Vitest 回归、类型检查及工作台打包；重启本地服务并检查实际页面。
