# 共用脑图小地图

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode `change`。Risk Level `L2`。Task Type `feature`。Active Playbooks `frontend-vue（primary）`、`testing`。

- M1 OPM 和业务脑图都能从画布左下角开关小地图，初始收起。展开后同步显示当前布局、选中节点和视口范围，适配缩放、分支聚焦、节点折叠和全屏。
- M2 点击小地图跳转，拖动蓝色视口框平移，聚焦小地图后可用方向键平移。导航只操作当前画布的坐标，不产生脑图编辑或撤销记录。
- M3 窄屏和画布尺寸变化后仍可操作，与原有缩放控件互不覆盖。

范围为共享脑图视图及测试，无保存契约或依赖变更。使用当前布局与视口坐标实现投影，保留现有画布入口。通过组件测试和两种脑图的隔离浏览器操作验收。回滚时撤回本规格对应的前端改动。

核对项引用 M1–M3。边界确认仅涉及画布导航。
