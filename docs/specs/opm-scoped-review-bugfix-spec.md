## 验收

- REV-01：本图完整审查；父级/祖先、相关子图、共享身份图仅做相关一致性检查；同名不同身份不联动；无关 OPD 不进入审查。快照明确范围与前后数据，历史未改变问题仅警告，明确的新冲突仍阻断。
- REV-02：格式缺项与引用错误提供字段路径、错误引用所属图、可复制合法身份列表；不接受缺项、伪造、截断或错图引用，不静默修正报告。
- REV-03：每个审查会话最多 3 次无效报告提交，达到上限立即中断该次审查，保留预览并显示具体原因；迟到工具/报告不能恢复 ready。
- REV-04：生成、审查、修正各自具有阶段超时；超时显示相应错误，预览保持 blocked；人工停止仍显示 stopped 并取消。失败可重新审查同一未提交方案，仍校验令牌和分析修订，成功后一次确认。
- REV-05：助手面板显示真实失败原因、审查范围与重新审查入口，未完成审查不能应用；组件及实际浏览器验证预览与恢复状态。
- REV-06：原有生成、脑图转换/修正、停止、一次确认及防越权回归通过。真实日志回放验证更具体诊断；在隔离数据上做实际 DeepSeek 生成/审查验证，记录时间与结果，不将一次成功视为普遍语义质量保证。
