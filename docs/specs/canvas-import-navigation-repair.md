## 范围与验收

目标是连续导入后使用正确文件和最新模型，并准确显示原始总图、展开图及放大图的导航。非目标是合成全景图、改变 OPM 细化语义、自动删除旧业务数据或重设计画布。

允许修改本仓库工作台导航显示、排序、对应测试及工作台打包脚本；允许配套修改 opm-platform 画布导入组件、工作台服务、对应测试和内置工作台包。禁止修改公共 API、数据库 schema、模型文件、鉴权和无关模块；不引入新依赖。沿用现有导航字段，通过宿主元数据恢复展示层级，不将展开关系伪装成运行时 in-zoom。

- IMPORT-01：重新选择文件清除旧解析结果；超限重新选择时替换当前文件；无效文件不能继续提交旧预览。
- IMPORT-02：明确追加与替换的含义，保留现有默认追加方式，导入完成打开最新模型根图。
- IMPORT-03：已有环境关联落后于主题草稿时，干净模型重新关联最新草稿；脏草稿或尚未同步的修改须明确阻止，不覆盖。
- NAV-01：保留根图真实名称，根图优先、兄弟图按自然名称顺序排列；兼容原生 SD 的默认标签。
- NAV-02：宿主导航保留导入展开图的父子关系；不创建虚假语义细化边，不越过运行时删除限制；保存再打开保留层级。
