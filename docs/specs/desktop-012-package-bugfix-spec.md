# macOS 0.1.2 重建与设置窗口关闭修复

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Active Playbooks：none (primary)、testing。

## 目标与根因

按用户要求重新生成 macOS Apple Silicon 安装包，保留旧版本。修复此前已定位的设置窗口关闭异常：`closed` 回调读取已经销毁的 `target.webContents.id`，引发 `Object has been destroyed`；创建时缓存身份供关闭回调清理。原 smoke 未单独关闭设置窗口，遗漏该生命周期路径。

非目标：不修改模型生成逻辑、公共 API、数据库 schema、权限规则、依赖版本，不发布外部或签名公证，不替换正在运行的用户应用，不配置或携带真实 API Key。

## 边界与契约

允许修改 `apps/desktop/src/main.mjs` 的窗口身份清理、桌面 smoke 回归、桌面版本及 lock 对应版本、桌面说明、本规格和检查清单；允许重建 Web/JAR 与桌面装配产物，使用 `.runtime`、`out/0.1.2` 和系统临时目录。Java/Node 复用已验证分发运行时，准备资源前保存到独立目录，防止源目录被装配脚本清理。

禁止修改 `.harness`、业务契约、用户数据/配置、前序未提交内容和旧安装包。无新增依赖。测试在全新工作区运行；打包态通过独立 `CFFIXED_USER_HOME` 隔离系统应用目录。

## 验收

- P1：真实旧应用单独关闭设置窗能复现异常；修复后重复关闭/重开无异常，主窗口可继续调用设置和状态。
- P2：桌面自动化回归通过；最终 0.1.2 应用在隔离 SQLite 上完成真实画布编辑、保存、重开、备份恢复及正常退出，子进程回收。
- P3：资源全量摘要与禁入文件检查通过，包内不包含真实凭证或用户数据库。
- P4：生成独立 0.1.2 应用和 DMG，校验映像及挂载内容，保存大小、SHA-256；保留旧包。

## Plan / Checklist 边界确认
