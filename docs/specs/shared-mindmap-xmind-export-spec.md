# 共用脑图 XMind 导出

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode `change`。Risk Level `L2`。Task Type `feature`。Active Playbooks `frontend-vue（primary）`、`testing`。

- E1 业务脑图和 OPM 脑图的导出菜单提供 XMind。一个文件包含一张工作表，导出范围是整张脑图，含暂时折叠和聚焦范围外的节点。
- E2 工作表保留主题、层级、同级顺序和纯文本备注。原生 JSON 用于携带建模分类、绑定及关系数据，XMind 用于主题交流。
- E3 文件在浏览器生成并下载。导出结果使用独立的 ZIP 工具和本项目 XMind 导入入口检查。

范围为共享脑图菜单、XMind 文件生成及测试。非目标为旧版 XML 导出、样式映射和模型语义迁移。复用现有分析文档及下载逻辑。数据库、分析接口和依赖沿用现有契约。回滚时撤回本规格关联的前端改动。

核对项引用 E1–E3。边界确认仅涉及文件导出。
