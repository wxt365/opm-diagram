Work Mode：change；Risk Level：L3；Task Type：bugfix；Active Playbooks：frontend-vue（primary）、testing。

## Lean Spec

目标：K1 业务建模／业务脑图 Enter 发送，Shift+Enter 换行，保留 Ctrl/Cmd+Enter；中文输入法选字、Alt+Enter 和长按回车不误发。K2 两类助手只为最近一条用户消息提供更正入口；有助手回复时仍可更正最近问题，旧消息无入口，生成、只读、忙碌时不可更正。K3 用户补充截图后确认：更正后界面只显示修订后的问题与新回复，不能出现两个用户气泡。内部保留审计历史，不回滚已保存模型。

允许：两个助手组件及测试、助手 prompt 路由／消息投影／生成接入及测试、助手 README、本规格与验证记录。prompt 新增可选 editMessageId，只接受当前会话最近用户消息；旧客户端省略时保持追加行为。会话文件只追加 supersedes 审计字段，无数据库迁移；返回 messages 投影省略被替代轮次，内部原文保留。禁止：数据库／正式模型 schema、依赖、流式脑图功能、无关文件和前序修改。不提交或打包。

事实／复现：业务输入框仅绑定 ctrl.enter/meta.enter，因此普通 Enter 不发送；两个助手逐条展示用户消息更正按钮，未限定最近问题。OPM 已有 Enter 发送及输入法保护。原测试覆盖 OPM 单轮回车／更正，没有覆盖业务回车和多轮入口。
