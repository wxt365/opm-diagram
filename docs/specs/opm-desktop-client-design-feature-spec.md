## 目标与非目标

根据用户确认，本轮完成桌面客户端的需求与设计文档，为后续实现提供边界和可执行验收。目标平台为 macOS 与 Windows，本地业务数据使用 SQLite，安装后不依赖用户另行部署数据库或开发工具。

本轮不实现客户端、不引入依赖、不构建安装包、不调用大模型、不签名发布、不改动真实数据或运行中服务。自动更新、云端同步、多人协作及其他桌面操作系统不纳入首版。

## 当前证据与设计前提

- 原架构明确允许增加桌面壳，但不能改变应用/领域契约；发布态曾规划为本地服务提供静态前端，不等于当前已有可分发应用。
- `StorageConfiguration` 当前支持 SQLite / PostgreSQL，省略类型走 SQLite；桌面版显式选择 SQLite。
- `apps/web/vite.config.ts` 当前开发代理承接 Runtime、bootstrap 和助手；生产客户端需要对应入口，不能依赖 Vite。
- Runtime 通过 `/opm-bootstrap.js` 注入本地会话；助手要求 API Key，且 `toolOrigin` 当前根据配置端口预先生成。不能假定无 Key、随机端口和打包路径已兼容。
- 当前 POM 以 Java 17 编译、要求 JDK 17 或以上；旧技术基线写 Java 21。设计须标明差异，不顺手改动语言版本。
