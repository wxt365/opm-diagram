# 共用脑图编辑与交换

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode `change`。Risk Level `L3`。Task Type `feature`。Active Playbooks `frontend-vue（primary）`、`backend-springboot`、`testing`。

- A1 两种脑图共用可收起大纲，点击定位，可原地改名。同级顺序与跨分支移动沿用节点 ID，并作为单次撤销事务。
- A2 画布支持原地编辑，创建节点后进入编辑。拖动预览同级前后与子节点落点，禁止循环。搜索支持结果计数和循环切换，支持聚焦分支和返回根节点。只读模式可导航。
- A3 Markdown 标题和列表导入到当前选中分支，保留原节点与正式模型。提供当前显示范围的 PNG、SVG 导出。原生 JSON 继续负责完整交换。
- A4 OPM 画布投影现有关系说明。业务脑图新增可选 `relations` 数组，记录有名称的分析关联，支持端点定位、删除、撤销、保存和交换。已保存的无关联文档继续有效。关联在预览前仅作为分析线索。

范围限于共享脑图、两个分析适配器、业务分析的可选文档字段与校验、相应助手分析提示与测试。正式模型 API、数据库表结构、引擎、依赖、XMind、小地图和皮肤不在本次范围内。

实施顺序为 A1–A2、A3、A4。验收以定向组件测试、后端回归和隔离模型的浏览器操作为准。回滚前先导出包含关联的业务脑图，旧运行时使用可选字段扩展前的数据快照。

核对项引用 A1–A4。边界确认：前端展示共用，领域保存和转换分别沿用现有适配器。
