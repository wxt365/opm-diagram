# 共用脑图 XMind 导入

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode `change`。Risk Level `L2`。Task Type `feature`。Active Playbooks `frontend-vue（primary）`、`testing`。

- X1 两种脑图通过「导入脑图」读取含 `content.json` 或 `content.xml` 的 XMind 文件，预览各工作表的主题和节点数量。用户确认一张工作表后，将主主题和从属主题追加到选定节点。
- X2 保留标题、纯文本备注、层级和同级顺序。预览说明图片、样式、独立主题及 XMind 关系线的导入边界。为导入节点分配本模型身份，OPM 节点进入待分类状态。
- X3 取消、文件错误、节点容量不足或目标失效时保留现有内容。成功导入作为一次撤销操作，沿用分析保存。解析在浏览器本地完成，文件最大 32 MiB，主题正文最多解压 4 MiB。

变更范围是共享解析器、导入预览、两个分析适配器及测试。正式模型契约、分析文档版本、数据库、依赖和已有交换格式沿用现有实现。小地图和 XMind 导出另议。

按解析、预览、两种适配器接入的顺序实施。验证使用新旧格式、损坏和容量边界的定向测试，以及隔离模型的保存重开。回滚时撤回前端改动，已追加的主题仍是原生脑图节点。

核对项引用 X1–X3。边界已确认，复用现有脑图编辑与保存入口。
