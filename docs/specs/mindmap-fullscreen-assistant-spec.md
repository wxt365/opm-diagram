# 脑图全屏助手与画布空间

> 上游历史参考：本仓库仅迁入 OPM、SQLite 与桌面相关部分；业务建模、PostgreSQL 和内网部署不在范围内。原文状态及验证结果不自动适用于本仓库，实际迁移验证见 README 的迁移策略与本次迁移报告。

Work Mode `change`。Risk Level `L2`。Task Type `feature`。Active Playbooks `frontend-vue（primary）`、`testing`。

业务建模与 OPM 共用脑图编辑体验。全屏时可以展开助手并继续当前分析对话，普通脑图分析视图使用底栏腾出的画布空间。

- A1 两种脑图全屏时都能打开和收起右侧悬浮助手，默认收起。全屏和普通视图复用同一个助手实例，保留会话、未发送输入和进行中的请求。
- A2 脑图分析隐藏整个底栏并释放高度。回到正式建模后恢复底栏标签和展开状态。用户主动运行正式模型检查或本体生成时，结果在正式建模视图中展示。
- A3 退出全屏后助手回到导航区。转换流程切换到正式画布时退出脑图全屏。
- A4 全屏时可拖动顶部把手移动助手，通过任一下角调整宽高。窗口限制在脑图工作区内，窄屏时适配可用空间。把手支持方向键。
- A5 在同一页面收起再打开助手时保留位置、大小和未发送输入。

范围为 `apps/web` 的共享脑图、工作台布局、助手接入及定向测试。会话身份、助手接口、后端、数据库、依赖、配置、正式模型和图谱分析行为沿用现有契约。

验证使用定向组件测试、类型检查、定向 lint 和隔离模型的浏览器操作。回滚时撤回本规格对应的前端改动。

核对项引用本规格 A1–A5。确认仅调整表现层，复用现有助手实例和保存保护。拖动和缩放调整仅涉及共享脑图组件及其测试。
